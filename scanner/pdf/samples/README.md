# samples/

Test images to measure the quality of the PDF and of the OCR.

- Only documents with permission to use them. Nothing with real personal data.
- For each image, if possible, a `.txt` with the expected text (same name) to measure OCR errors.
- Cases to cover: clean text, small print, accents (es/ca), tables and columns, a skewed page,
  shadows and glare, faint text, stamps and signatures.
