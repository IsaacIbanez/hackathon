# muestras/

Imágenes de prueba para medir la calidad del PDF y del OCR.

- Solo documentos con permiso para usarlos. Nada con datos personales reales.
- Por cada imagen, si se puede, un `.txt` con el texto esperado (mismo nombre) para medir errores de OCR.
- Casos a cubrir: texto limpio, letra pequeña, acentos (es/ca), tablas y columnas, hoja torcida,
  sombras y reflejos, texto tenue, sellos y firmas.
