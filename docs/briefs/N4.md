# Brief N4: read the whole PDF aloud

Confirmed by Didac on 2026-11-22. Task sheet: `docs/tareas/N4.md`. Branch: `feature/N4-leer-pdf` (from `main`, e867784).

## Goal
In overlay option 3 («Read a file aloud»), opening a **PDF** shows the **real PDF**, with a large **«Read the whole PDF»** button. The button reads it from start to end with the **local voice** ($0), **page by page and with no page limit**.

## Interview decisions
- **Viewer:** the PDF's pages, rendered by the reading service (pypdfium2, already installed). No new library is needed in the web app.
- **Voice:** the system's local one (Web Speech), at no cost and without sending the document anywhere.
- **Controls:**
  - the existing ones: pause and resume, previous and next line, repeat;
  - new: **stop** (back to the start), **speed** (0.75× to 1.5×), **previous and next page** and **go to a page**.
- **Long PDF:** by pages and without a limit. Reading starts as soon as the first page is ready, and the next one is prepared while the current one plays.
- **Highlighting:** a yellow box over the line on the PDF page and, below, the same line in very large type, like a subtitle.
- **Start:** it does not read on its own; it waits for the button or the Space key.
- **Language:** detected from the text itself (es, ca or en) and that language's voice is used if it is installed.
- **Tests:**
  - the 3 PDFs in `scanner/pdf/samples/print/`;
  - a generated PDF of about 40 pages, with made-up data;
  - a scanned PDF of 3–4 pages.

## Current status (read from the repo)
- Option 3 (`web/src/app/overlay/ReadFileMode.tsx`) follows this chain:
  1. `OpenAndReadFile` (Go);
  2. `POST /document` (`scanner/documents.py`);
  3. `GuidedReader`, which reads the whole file on its own, as lines in large type.
- There is no viewer.
- `documents.py` reads at most 30 pages per PDF, and OCRs at most 8.

## Scope
**Reading service** (`scanner/`):
- The PDF is opened once and kept in memory (the last 3).
- Each page is served separately: its image and its lines with their box normalised to that page.
  - Page with text: the text comes from the PDF.
  - Scanned page: it goes through the pipeline's OCR.
- No page limit.

**Go** (overlay):
- Bindings to open a PDF (dialog and sending it to the service) and to ask for a page: image as a data URL and lines, in JSON.
- The matching client in `backend/scanner/`.

**Web** (`web/src/document/`):
- Pure logic for reading by pages, with tests:
  - automatic advance between lines and pages;
  - a «Page N of M» notice;
  - preloading the next page;
  - stop, speed, previous and next page, go to a page.
- The viewer's view:
  - the page with the box and the subtitle;
  - a large button and controls with keys;
  - an `aria-live` region for the screen reader.

**Overlay:** `ReadFileMode` opens the viewer when the file is a PDF. The other types keep the line view.

| Action | Keys (besides the buttons) |
|---|---|
| Read all / pause and resume | Space · Num 5 |
| Previous / next line | ← → · Num 4 / Num 6 |
| Repeat | R · Num 8 |
| Stop | X |
| Faster / slower | + / − |
| Previous / next page | PgUp / PgDn |
| Go to a page | G |

## Out of scope
- Cloud voices.
- A viewer for other formats: TXT and images keep the line view.
- Option 2 (paper with the camera).
- Volume (N9).
- The keypad keys: N2 adds them; here the logic is left ready for it to use.

## Result (2026-11-22, real `.exe`, Windows 11)
- **40-page PDF:**
  - opens in 93 ms and each page arrives in 27–37 ms;
  - with Space it starts reading at once: «Page 1 of 40» and the first line, with the box right over it and the large subtitle;
  - PgDn and PgUp work (it went to page 39), G with 40 (page 40), + (1.25×) and stop (back to page 1 without speaking; it was S then, today it is X).
- **Scanned 3-page PDF:**
  - page 1 goes through OCR: 11.5 s the first time, with a cold OCR;
  - meanwhile, the viewer shows «Preparing page 1…»;
  - the box lands correctly on the lines read with OCR.
- **The 3 sample PDFs:**
  - open in less than 100 ms;
  - the Catalan notice is detected as ca-ES;
  - the letter, read at 1.5×, reaches «End of document» and the button changes to «↺ Read it again».
- **Tests:**
  - Python: `scanner/test_service.py`, 39 out of 39, with 6 new ones in `TestPdfPages`;
  - Go: `backend/scanner/pdf_test.go`;
  - web: `web/src/document/test/pdfReader.test.ts`, 12 tests.
- **New samples:** `scanner/pdf/samples/print/04-condiciones-40-paginas.pdf` and `05-escaneado-3-paginas.pdf`, generated with `make_print_samples.py` and with made-up data.

## Contract

## Risks
- Voices change from one machine to another.
- The OCR of a scanned page takes 3–8 s; if it is slower than the reading, it says so aloud.
- A huge PDF takes memory in the service: only the last 3 opened are kept.
