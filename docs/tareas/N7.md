# N7. Summarise with AI: the document and the selected text

Owner: unassigned · Depends on: N5, N6 · Board: `TAREAS.md` · How to start: `docs/TRABAJAR.md`.

## Goal
Summarise with AI: the document and the selected text.

## Current status
**Branches:** since #44 (2026-11-22), `main` holds the integration (#38), the per-person startup (#39), guided reading (#40) and the overlay app. What is cited from `feature/T6-camera-controls` (#41, Nil) is not in `main` yet: check whether it has been merged already.

- **There is no «summary».**
- **The closest thing is Go's explanation** (`backend/session`): when a `document` arrives over the WebSocket or through `POST /message`, Go asks for a simple explanation. It works like this:
  - it uses `explainPrompt` and `CompleteWithEscalation`, with the cheap model first and the expensive one if it is unsure;
  - it answers in JSON with the text and the blocks to highlight;
  - the cost shows up in `stats`.
- **The overlay does not use it yet:** `docs/OVERLAY.md` leaves it «unconnected, so as not to spend».
- **Models:**
  - by default, Haiku and Sonnet (paid);
  - `LLM_PROFILE=dev` puts free models first, but escalates to Haiku (`docs/historial/ESTADO_PROYECTO.md`).
