# N1. Solid overlay

Owner: Nil · Depends on: — · Board: `TAREAS.md` · How to start: `docs/TRABAJAR.md`.

## Goal
A solid overlay. It is the first thing to do. It does not have to be pretty, but it has to work well: the application must be fully usable with the mouse alone. The overlay has a camera at the top left showing the hand points and other detections. It must make clear how new buttons or panels are added, because other tasks build on top of it.

## Current status
**Branches:** since #44 (2026-11-22), `main` holds the integration (#38), the per-person startup (#39), guided reading (#40) and the overlay app. What is cited from `feature/T6-camera-controls` (#41, Nil) is not in `main` yet: check whether it has been merged already.

Read in `main` after #44 (Didac's overlay; brief in `docs/historial/briefs/isaac.md`):
- **Global shortcut and window.** `app_overlay.go` and `backend/overlay/` (`hotkey_windows.go`, `RegisterHotKey`): Ctrl+Alt+Space (changed with `LAUZHACK_HOTKEY`) shows and hides the window, which stays always on top. Only done on Windows; on Linux and macOS the window stays open (`hotkey_other.go`).
- **Menu.** `web/src/app/overlay/Overlay.tsx` + `modes.ts`: three options:
  - 1, gestures;
  - 2, read a paper;
  - 3, read a file.

  Each option is a button (click) and a key (1–3 or Num1–3). D opens the previous screen (`App.tsx`), Q quits and Esc goes back.
- **How to add an option.** Comment in `modes.ts`: «add an entry to `MODES` and a component to `MODE_VIEWS` in `Overlay.tsx`». `ready: false` shows it as «coming soon». More detail in `docs/OVERLAY.md` («Adding an option»).
- **Helper processes.** `backend/overlay/procs.go` starts and stops `scanner/service.py` (8770) and `gesture-control.exe` (`adapters/desktop`, 8767).
- **Camera with the hand points: it does not exist in the overlay.**
  - Drawing the skeleton, the pose and the menu exists in `web/src/input/overlay.ts` (Nil, #29), but the previous screen uses it (`web/src/app/Gestures.tsx`).
  - Option 1 launches Gesture Control as a separate program, with its own window (`web/src/app/overlay/GesturesMode.tsx`).
- **Tests.** The `overlay` branch passes `task check` (136 web tests and 8 Go packages) and `wails build` (checked before #44), but the person writing this has not verified real use. Isaac's brief marks as tested the build with `task overlay`, the shortcut and options 1–3 without real paper.

## «Done» criteria (draft, to be confirmed with the person)
- Everything on the agreed list can be used with the mouse alone; checked by going through it without touching the keyboard.
- The camera shows at the top left with the hand points live.
- Without a camera (or with the camera busy), a clear message, and the app is still usable.
- A short guide on how to add a button or panel, tested by adding a sample one.
- `task check` and `wails build` green.
