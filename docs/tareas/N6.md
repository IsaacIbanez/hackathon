# N6. Text selection in cursor mode

Owner: unassigned · Depends on: N5 · Board: `TAREAS.md` · How to start: `docs/TRABAJAR.md`.

## Goal
Text selection in cursor mode.

## Current status
**Branches:** since #44 (2026-11-22), `main` holds the integration (#38), the per-person startup (#39), guided reading (#40) and the overlay app. What is cited from `feature/T6-camera-controls` (#41, Nil) is not in `main` yet: check whether it has been merged already.

- **There is no text selection** on any branch: `git grep -i "getSelection\|selection"` only finds the `select` gesture, which is something else.
- **The closest things:**
  - the hand module's `select` gesture (holding the finger still ~0.9 s, `web/src/input/interaction.ts`), which today means «explain this to me»;
  - the document's **blocks**: lines with a box and a confidence in the contract (`api/openapi.yaml`, `TextBlock`). A selection could be made by blocks.
- **Selectable text depends on the source:**
  - a PDF with a text layer and the scanner give text;
  - an image without OCR does not.

## Open questions
For the person who picks up the task; they cannot be answered by reading the repo.
- How text is selected: with the mouse, with a gesture (which?) or with the keypad.
- Which unit is selected: words, lines (blocks) or free areas.
- Which text is selectable: only documents with text (PDF with a text layer or scanned with OCR) or images too (OCR would be needed).
- What is done with the selection: read it, summarise it (N7), copy it.

- Tested with a PDF with text and with a scanned document.
