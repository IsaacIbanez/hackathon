## Log (filled in by the agent)
For each bug: symptom → how to reproduce it → cause → fix → how it was checked (with the `.exe`).

**1. A gesture suspended the computer**
- Cause: the gesture menu offered «Computer ▸» (suspend, restart, shut down) with a confirmation that was also by gesture, and two touches in a row can confirm it by accident.
- Fix (branch `feature/R2-gestures-safe`): power is **disabled by default**. The menu does not offer «Computer ▸», and Go rejects those actions even if they are requested (`Executor.AllowPower`). It is only enabled with `LAUZHACK_GESTURES_POWER=1` (or `-power` in `gesture-control`).
- Checked with tests: `TestExecutorPowerOffByDefault` in Go and the menu in `desktop.test.ts`. Still to check with the `.exe`: 5 minutes of use without `did: suspend` in the log.

**2. The volume jumped (20 → 100 → 50 → 0 %)**
- Cause: a detector glitch in a single frame (a lost finger) counts as a very open or closed pinch, and that value went straight to the system.
- Fix:
  - readings more than 25 % away from the previous one are ignored, unless they hold for 3 frames in a row, which is a real movement (`levelMaxJump`, `levelJumpFrames` in `interaction.ts`);
  - the value sent to the system changes by at most 20 % at a time, and the confirmed value is the exact one.
- Checked with the test «a one-frame glitch in the pinch doesn't move the volume», which makes a fake one-frame jump up and another down. Still to check with the `.exe`.

**3. Mic only in Google Meet**
- Already fixed earlier (commit 568d818): the menu's «Microphone» mutes the system microphone. Call actions no longer send the shortcut to another window if they cannot find the call.

**4. Sharing the camera with PDF Scanner**
- Since N1, the gestures release the camera while option 2 (or the developer screen) is open, and get it back when you leave.
- New: if the camera is still busy on return, it retries four times, every 0.7 s, with the notice «Waiting for the camera…», before giving the error.
- Still to check with the `.exe`: gestures → option 2 → gestures.
