## Ports (all on 127.0.0.1)
8765 app and real server · 8770 reading service (`scanner/service.py`) · 8767 standalone Gesture Control · 8080 mock · 5173 Vite (`npm run dev`).

## Main flows
- **PDF Scanner:** `web/src/camera` (photo) → `POST /scan` in Go → `scanner/service.py` (OCR) → `document` → guided reading (`web/src/document`).
- **Transcribe:** mic or call (`web/src/captions`) → `GET /captions` → `backend/captions` → Together AI → captions, who is speaking, translation and a `.txt` in `Documents/LauzHack/`.
- **AI Summary:** selection in any program (`backend/overlay`) → `backend/summary` → cheap model → bubble.
- **Gestures:** camera → MediaPipe (`web/src/input`) → action → `adapters/desktop` (real keys); there is a single camera, shared between tools (`gestureHost.ts`).

## Structure rules (verified)
- No `internal/` folders (the root `main.go` could not import them): packages go in `backend/<name>`.
- Frontend in `web/` (`"frontend:dir": "web"`, `//go:embed all:web/dist`); `web/wailsjs/` is generated by Wails.
- Taskfile instead of make; Go ≥ 1.26.
