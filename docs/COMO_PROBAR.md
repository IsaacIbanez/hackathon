# How to test

Moved from `AGENTS.md` on 2026-11-22 (summary there).

1. **Key (once):** create `.env` in the root (it is in `.gitignore`; the key is passed by chat, never through git):
   ```
   OPENROUTER_API_KEY=sk-or-v1-...
   LLM_PROFILE=dev
   ```
   `LLM_PROFILE=dev` puts **free** models first (sometimes slow or saturated), but **does not guarantee $0**: the expensive tier is Haiku (paid) and `/transcribe` tries Gemini first. To spend nothing, set `LLM_CHEAP_MODEL`, `LLM_EXPENSIVE_MODEL` and `LLM_TRANSCRIBE_MODELS` to `:free` models only (see `docs/historial/ESTADO_PROYECTO.md` §4).
2. **Server:**
   - `task server` → real logic (session + models) on `127.0.0.1:8765` (`/ws`, `POST /message`, `POST /scan`, `/health`). Without Didac's reading service, start it with `SCANNER_URL=fixture` and `/scan` will answer with the sample form (with `pageCorners`).
   - `task mock` → fixed answers on `localhost:8080`, no key and no cost.
   - `task dev` → the full desktop app (Wails), with the real server inside if there is a key.
3. **Interface in the browser:** `cd web` and `VITE_WS_URL=ws://127.0.0.1:8765/ws npm run dev` (PowerShell: `$env:VITE_WS_URL="ws://127.0.0.1:8765/ws"; npm run dev`). «Developer tools» → **Send sample document** to test without the scanner; «Turn on hand gestures» for the gestures (step-by-step guide: `docs/PROBAR_GESTOS.md`).
4. **Scanner (B):** send your `document` with `POST /message` → guide `docs/INTEGRACION_SCANNER.md`, example `python api/examples/send_message.py --demo-ocr`.
5. **Desktop app (executable):** `wails build` → `build/bin/lauzhack.exe` (double click). It looks for the `.env` in the current folder, next to the `.exe` and up to 3 folders above (the repo root). Log in `build/bin/lauzhack.log`. «Developer tools» shows what the window supports (Spanish voices, dictation, camera).
6. **Overlay:** `task overlay` (or `wails build`) → `build/bin/lauzhack.exe`, a single executable with Gesture Control inside; Ctrl+Alt+Space or key 1 of the MX Keypad opens it. See `docs/OVERLAY.md` and `docs/KEYPAD.md`.
   - **Options 2 and 3** (paper and file): the app starts `scanner/service.py` with `scanner/pdf/.venv`. Without that environment it no longer falls back to the system Python (which died with `No module named 'cv2'`, see `build/bin/reading-service.log`): the screen gives the install command. Install it once with `powershell -ExecutionPolicy Bypass -File scanner\pdf\scripts\install.ps1`, which also installs Tesseract (needed for paper and scanned PDFs).
   - **Seen in the test on 2026-11-22:**
     - if another program owns Ctrl+Alt+Space, use keypad key 1 or Ctrl+Alt+Shift+1;
     - with the gestures, the menu once **suspended the computer** (`did: suspend` in the log) and the volume pinch jumped down to 0 % (Nil's code: fixed in R2);
     - muting the mic only acts on an open Google Meet call.
7. **Before the PR:** `task check`.

Ports: 8765 app/real server · 8766 `scanner/capturar.py --servidor` · 8080 mock. Demo script: `docs/PITCH.md`.

**Structure rules (verified, do not change without telling the team):**
- No `internal/` folders: the root `main.go` cannot import them (Go rejects it). Packages go in `backend/<name>` and are imported as `<module>/backend/<name>`.
- The frontend lives in `web/`, with `"frontend:dir": "web"` in `wails.json` and `//go:embed all:web/dist` in `main.go`.
- `backend/cmd/mock` is a separate `main` for testing without Wails.
- `web/wailsjs/` is generated by Wails: it is not edited by hand.
