# web/ (React + Vite + TypeScript + Tailwind)

The interface inside the desktop app. It captures the camera and the mic and does the cheap work locally.

| Folder | Owner | Contents |
|---------|-------|-----------|
| `src/api` | role A | types generated from the contract (`types.ts`, do not edit) and aliases (`index.ts`) |
| `src/app` | role A | app, connection, voice (`voice.ts`), cost meter and the **gesture bridge** (`bridge.ts`, `Gestures.tsx`) |
| `src/camera` | role B1 | camera flow, document detection and cropping, local OCR |
| `src/document` | role B2 | document view, highlighted fields |
| `src/input` | role C | hand gestures (MediaPipe) and voice |

Read `../api/` (the contract) first and only your folder.

## How to start it
- With a window: `task dev` (`wails dev` from the root).
- Without a window: `task mock` in the root and `npm run dev` here; open the Vite URL in the browser.
- WebSocket URL: inside Wails it asks Go for it (`WsURL()`, normally `ws://127.0.0.1:8765/ws`); outside Wails it uses `VITE_WS_URL` or, by default, the mock (`ws://localhost:8080/ws`).
- `wailsjs/` is generated by Wails: it is not edited by hand.

## Gesture bridge (`src/app/bridge.ts`)
Turns the hand module's events (role C, `src/input`) into contract messages:

| Gesture (action from `src/input`) | Message | Spends AI? |
|---|---|---|
| ☝️ point | `pointer` with the document's x, y (max 5/s); Go finds the block and reads it | No |
| ☝️ hold (`explain_here`) | `pointer` + `utterance` «¿Qué pone aquí y qué tengo que hacer?» (What does it say here and what do I have to do?) | Yes |
| 👍 `read` | `utterance` «Léeme el documento.» (Read me the document.) | Yes |
| menu → `ask_for_help` | `utterance` «Necesito ayuda con este documento.» (I need help with this document.) | Yes |
| ✋ `pause`, menu → `repeat`, 🤏 `volume` | local voice control | No |
| menu → `dictate` | `onDictate` hook (voice input: role C) | — |

**Provisional:** until it is decided who owns the camera, `Gestures.tsx` takes the camera's whole image as the document (`WHOLE_FRAME`).
Tests: `npm test` (`src/app/test/bridge.test.ts`).
