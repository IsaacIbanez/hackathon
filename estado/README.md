# estado/

Un archivo por agente: `P1-C.md`, `P1-G.md`, …, `P4-G.md`, creado a partir de `_PLANTILLA.md`.

- Cada agente escribe solo en su archivo. Así no hay conflictos de Git entre agentes.
- Al empezar una sesión, lee tu archivo para retomar donde lo dejaste.
- Al terminar, actualízalo y haz commit.
- Un humano puede leer todos los archivos de esta carpeta para ver el estado general.
